01实验目标

本节的重点不是调用 nn.Linear，而是亲手写出「学习参数」的完整链路： 参数怎样初始化、前向传播怎样得到预测、损失怎样把误差传回每一层、梯度怎样更新 W 和 b。 只有把这四步拆开看，才能真正理解 MLP 在学什么。

  • 实现：用纯 JavaScript 实现两层隐藏层的 MLP，包括 He / Xavier 初始化、ReLU / Tanh / Sigmoid 激活、二元交叉熵损失和手写反向传播。
  • 训练：实现 mini-batch SGD、Momentum 与 Adam 三种参数更新方式，并在双月、同心圆、螺旋、XOR 四类二维非线性数据上训练。
  • 可视化：实时绘制决策边界、损失与准确率曲线、网络权重图、第一层权重热力图、输出层权重与参数分布直方图。
  • 分析：对比学习率、激活函数、网络深度与优化器对收敛速度和最终结果的影响，解释参数变化与分类边界之间的关系。
02MLP 原理

2.1 网络结构

输入是二维特征 x = (x₁, x₂)，经过若干隐藏层后输出一个 0–1 之间的概率。 每个隐藏层做「线性变换 + 非线性激活」：

z(l) = W(l) a(l−1) + b(l)，   a(l) = g(z(l))，   ŷ = σ(z(L)) g 为隐藏层激活函数，σ 为输出层 Sigmoid

本页默认使用 [2, 16, 16, 1] 的结构。参数形状与数量如下：

2.2 损失函数

二分类使用二元交叉熵（BCE），它衡量预测概率与真实标签之间的差异：

L = − (1/N) Σi [ yi log ŷi + (1 − yi) log(1 − ŷi) ]

2.3 反向传播

反向传播本质上是链式法则。输出层刚好是 Sigmoid + BCE，因此误差项的起点非常简洁：

δ(L) = ŷ − y 输出层误差
δ(l) = ( (W(l+1))T δ(l+1) ) ⊙ g′(z(l)) 误差逐层回传，⊙ 表示逐元素相乘
∂L/∂W(l) = δ(l) (a(l−1))T，   ∂L/∂b(l) = δ(l)

实现时缓存每一层的 z 和 a，反向时直接复用， 避免重复计算。为了确认手写梯度没有写错，我用中心差分做了数值校验， 两层隐藏层网络的最大绝对误差约为 1.2 × 10−10。

2.4 参数更新

W ← W − η · ∂L/∂W，   b ← b − η · ∂L/∂b

在基础 SGD 之上，页面还实现了两种常用改进： Momentum 累积历史梯度形成“惯性”，减少震荡； Adam 同时估计梯度的一阶矩和二阶矩，并为每个参数自适应调整步长。

2.5 激活函数

激活函数表达式导数特点
Tanh(ez − e−z) / (ez + e−z)1 − tanh²(z)零中心，边界平滑，适合小网络
ReLUmax(0, z)1 (z > 0)，否则 0计算快，缓解梯度消失，边界偏折线
Sigmoid1 / (1 + e−z)σ(z)(1 − σ(z))输出有界，深层容易饱和
03参数实现

页面中的所有训练逻辑都在 mlp-core.js 中，完全不依赖第三方库。 核心对象只有两个：MLP 负责前向与反向，Optimizer 负责参数更新。

① 参数初始化

Tanh / Sigmoid 使用 Xavier 初始化（方差 1/fan_in），ReLU 使用 He 初始化（方差 2/fan_in）； 偏置初始化为 0。合适的初始尺度能避免激活值一开始就饱和。

② 前向与缓存

逐层计算 z = aWT + b，保存每层的 z、a 和输入 a(l−1)， 供反向传播使用。

③ 反向与更新

从输出层误差 ŷ − y 开始，按链式法则回传， 得到每层 dW、db 后交给优化器更新。

一次 mini-batch 训练步骤 
// 取出一个 batch
const batch = subset(X, Y, order.slice(pos, pos + batchSize));

// 前向 + 反向：一次算完损失与所有梯度
const grads = model.lossAndGrad(batch.X, batch.Y);

// 优化器更新 W 和 b（SGD / Momentum / Adam）
optimizer.step(model, grads, lr);

每个 epoch 会重新打乱样本顺序，再按 batchSize 切成若干 mini-batch。 训练过程中页面记录每个 epoch 的损失、准确率，以及决策边界和参数快照。

如何读图

从参数到边界的解释链
  • 看边界：概率 0.5 的等高线就是分类器实际使用的边界，背景颜色体现置信度。
  • 看 W¹：每个隐藏单元把二维输入投影到一个方向，正负权重决定它响应哪一侧的区域。
  • 看 b：偏置控制神经元的激活阈值；改变 b 相当于把边界整体平移。
  • 看输出层：多个隐藏单元的响应被组合起来，单个神经元只能切一刀，组合后才能围出弯曲边界。
  • 看分布：权重是否过度集中或出现极端值，可以辅助判断学习率是否过大、是否发生震荡。

05结果分析

5.1 参数是怎样“学会”决策边界的

把训练前后的权重热力图对比起来看，会发现参数并不是随机地变化，而是有明确分工： 第一层把输入空间的不同方向分配给不同隐藏单元，第二层在这些单元的输出上再做组合， 输出层最后加权投票。单个隐藏单元只能表达“在某个方向上的半平面判断”， 多个单元叠加后，边界才能弯曲、闭合，形成双月或同心圆这样的形状。

偏置 b 的作用同样直观：它把激活阈值整体平移。当 b 为正时，单元更容易被激活； 当 b 为负时，需要更强的输入才能越过阈值。网络图中节点颜色的变化， 对应的就是每个神经元“默认倾向”的变化。

5.3 学习率的影响

学习率是最敏感的超参数。η = 0.001 时参数每次只移动很小一步，损失下降缓慢； η = 0.05 时收敛又快又稳。当 η 继续增大，更新步长可能超出损失曲面的“安全范围”， 参数会在最优解两侧来回跳动：在本文固定种子的那次实验里，η = 0.5 直接发散、准确率退化到 50%； 换一组初始化后，同样的学习率也可能只是收敛变慢或损失曲线剧烈震荡。 因此在交互面板里把学习率调大时，重点观察损失曲线是否抖动、权重分布是否出现极端值。

5.4 结构、激活函数与优化器

  • 深度与宽度：双月数据用 8 个隐藏单元就能达到 97.9%，说明简单问题不需要大网络；螺旋数据用 16-16 也常能达到 99% 以上，但不同初始化之间波动更大（测试中曾出现 87.9% 与 100% 的差异），说明复杂边界更依赖足够的有效分段和初始条件。
  • 激活函数：Tanh 的边界平滑，ReLU 的边界更接近分段直线，Sigmoid 在两端的导数很小，训练后期容易变慢。
  • 优化器：Adam 对学习率更宽容，通常几步就能把损失压下去；SGD 需要更大学习率；Momentum 能减轻 mini-batch 带来的抖动。
  • 容量与过拟合：当前准确率是训练集准确率，没有划分验证集；在噪声较大的数据上增加宽度，训练损失会继续下降，但不代表泛化更好。这是本实验的局限之一。
06代码实现

下面给出两份可以离线运行的参考实现：一份是 NumPy 从零实现（与页面逻辑一致）， 另一份是 PyTorch 对照版本，便于验证结果和理解框架内部等价的操作。 

import numpy as np

# ---------------- 网络定义 ----------------
class MLP:
    def __init__(self, sizes, lr=0.05, seed=42):
        rng = np.random.default_rng(seed)
        self.lr = lr
        self.W = [rng.normal(0, np.sqrt(1 / n), (m, n))
                  for n, m in zip(sizes[:-1], sizes[1:])]
        self.b = [np.zeros(m) for m in sizes[1:]]

    def forward(self, X):
        a, cache = X, []
        for i, (W, b) in enumerate(zip(self.W, self.b)):
            z = a @ W.T + b
            out = 1 / (1 + np.exp(-z)) if i == len(self.W) - 1 else np.tanh(z)
            cache.append((a, z, out))
            a = out
        return a, cache

    def backward(self, y, cache):
        delta = (cache[-1][2] - y[:, None]) / len(y)
        gW = [None] * len(self.W)
        gb = [None] * len(self.W)
        for i in range(len(self.W) - 1, -1, -1):
            a_prev, z, out = cache[i]
            gW[i] = delta.T @ a_prev
            gb[i] = delta.sum(axis=0)
            if i:
                delta = (delta @ self.W[i]) * (1 - cache[i - 1][2] ** 2)
        return gW, gb

    def step(self, gW, gb):
        for i in range(len(self.W)):
            self.W[i] -= self.lr * gW[i]
            self.b[i] -= self.lr * gb[i]

# ---------------- 训练 ----------------
net = MLP([2, 16, 16, 1], lr=0.05)
rng = np.random.default_rng(42)
for epoch in range(300):
    order = rng.permutation(len(X))
    for s in range(0, len(X), 16):
        idx = order[s:s + 16]
        p, cache = net.forward(X[idx])
        gW, gb = net.backward(y[idx], cache)
        net.step(gW, gb)

    eps = 1e-7
    p_full, _ = net.forward(X)
    p_full = p_full.ravel()
    loss = -np.mean(y * np.log(p_full + eps) + (1 - y) * np.log(1 - p_full + eps))
    if epoch % 50 == 0:
        print(epoch, round(float(loss), 4))

07小结

这次作业把 MLP 从公式拆成了可以逐行检查的代码：初始化、前向缓存、反向链式法则、mini-batch 更新。 真正把参数画出来之后，几个原本抽象的点变得很直观：

  • 隐藏层的权重决定“看什么方向”，输出层的权重决定“怎么投票”，偏置决定“门槛在哪里”，三者共同塑造决策边界。
  • 损失曲线和权重分布可以当作训练是否健康的体检指标：曲线剧烈震荡、参数出现极端值，往往意味着学习率过大。
  • 网络容量不是越大越好。简单数据用小网络就足够，复杂数据才需要更宽或更深的网络；同时还要警惕只提升训练准确率而忽略泛化。
  • 从零实现一遍之后，再回头看 PyTorch 的 loss.backward() 和 opt.step()，会清楚很多。
