AI Agent 使用情况报告

作者：YW-deal
日期：2026-10-22

一、调研说明

本次报告针对四个提供的AI Agent进行试用体验记录，记录本人实际使用频率、适用场景与使用感受，区分高频使用和低频使用的Agent。

二、各Agent使用概况

1. Trea （经常使用）

Trea是我日常使用频率最高的Agent之一。在日常资料整理、思路梳理、文本修改、作业辅助等场景都会优先选用，响应稳定，理解需求比较顺畅，可以高效完成文字类任务。

2. Workbody （经常使用）

Workbody同样属于高频使用的Agent，适合偏向实操、任务拆解、流程类的工作，适合规划分步任务，帮我把复杂需求拆成可执行步骤，在项目、计划类场景实用性很强。

3. Agent 3 （较少使用）

该Agent使用频次很低。不是功能缺陷，主要是适配我平时需求的场景不多，相比Trea和Workbody，没有形成固定的使用习惯，仅偶尔测试体验。

4. Agent 4 （较少使用）

第四个Agent使用同样偏少。它的能力方向和我现阶段的学习、工作匹配度不高，仅简单试用，没有纳入日常常用工具。

三、使用偏好总结

整体来看，我更偏好擅长文本处理、任务规划类的Agent。Trea和Workbody贴合我当下的学习需求，因此成为主力工具；另外两个Agent的定位和我的日常需求契合度较低，使用机会不多。

四、体验反思

不同AI Agent有各自擅长赛道，不存在绝对好坏，选择和自身任务场景匹配的Agent，才能更好发挥作用。

五、小结

本次试用四个Agent，高频：Trea、Workbody；低频：剩余两个。后续会继续在合适场景尝试低频Agent，探索它们独有的优势。
